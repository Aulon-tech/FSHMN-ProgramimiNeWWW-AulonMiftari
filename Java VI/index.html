Kalkulatori i buxhetit

Reflektim: 0, "0", null dhe NaN

  • 0 është numër i vlefshëm, por falsy në kushte.
  • "0" është string; është truthy (string jo bosh) dhe "0" + 1 jep "01".
  • null është mungesë e qëllimshme vlere; typeof null jep "object" dhe Number(null) jep 0.
  • NaN është i tipit number, por nuk është i barabartë as me veten; testohet me Number.isNaN().

Prandaj funksioni përdor typeof dhe Number.isFinite, jo if (!x), që do të refuzonte gabimisht 0.
